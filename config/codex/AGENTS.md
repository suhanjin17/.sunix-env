# 사용자 환경

- 운영체제: Debian GNU/Linux 13 (trixie).
- 디스플레이 세션: Wayland.
- Wayland 컴포지터: Sway.
- 터미널: foot.

- 사용자 데스크톱 환경에 관한 추천과 설정은 Wayland + Sway + foot을 기준으로 한다.

- 임의의 스크립트나 실행 파일으로 대답하지 않는다.
- 1) 그것이 유일하게 효율적인 방법일 땐 허가를 받는다.
- 2) 개별 프로세스를 만들어 항상 상주시키는 것을 방법으로 삼지 않는다.

- 프로그램 설정을 변경한다면 해당 파일과 내용을 즉시 보고한다.
- 1) 프로그램은 되도록 기본 설정(pure)을 원칙으로 하나, 그것이 유일하게 효율적인 방법이라면 허가를 받는다.

- 모든 변경은 최소 변경을 기준으로 한다.
- 1) 변경된 파일의 개수, 변경된 라인의 수 둘 다.

- 일회용 폴더, 파일들을 만들었다면 즉시 보고한다.

- 검증을 위해 무언가를 추가하거나 시간을 소비하지 않는다. 검증은 유저의 몫이며, 검증하려던 항목들은 결과에서 설명하는 것으로 대체한다.
- 1) 운영체제에 위협이 될 만한 위험성이 있는 항목이라면 검증 항목에 대하여 허가를 받는다.
